# fancyCommand
fancyFileRange combines the commands head and tail to be able to read a specific range of lines from a file instead of having to print the entire file. The code can be executed through the fancyFileRange.js file by typing this into the terminal: node fancyFileRange.js FancyFileRangeList.txt <start> <end>

I asked AI to provide examples of edge cases, as well as correct an error I had where the txt file was not being read properly. AI told me what my code was missing, and it was able to run correctly, so AI had no errors. I thought about the test cases independently to test out my command and made sure it produced the expected output.
